# Creating GitHub Repository - Step by Step Guide

## Quick Setup Guide

### Option 1: Using GitHub Web Interface (Easiest)

1. **Go to GitHub**
   - Visit https://github.com/new
   - Sign in if needed

2. **Create New Repository**
   - Repository name: `stock-prediction-cnn`
   - Description: "Stock Price Movement Prediction using 10-Layer 1D CNN"
   - Choose: Public
   - Check: "Add a README file"
   - Check: "Add .gitignore" → Select "Python"
   - Click "Create repository"

3. **Clone to Your Computer**
   ```bash
   git clone https://github.com/medalliagitlihz/stock-prediction-cnn.git
   cd stock-prediction-cnn
